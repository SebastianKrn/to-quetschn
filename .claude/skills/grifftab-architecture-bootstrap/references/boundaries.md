# Boundaries Reference

- `apps/web`: App Router, API stubs, env validation for web, user-facing flows.
- `apps/omr-service`: OMR HTTP service shell and provider invocation adapter.
- `apps/worker`: BullMQ workers and queue event handling.
- `packages/domain-types`: Canonical contracts and schema definitions.
- `packages/griffschrift-engine`: Mapping heuristics.
- `packages/renderer-svg`: Rendering contracts and SVG generation.
- `packages/omr-provider`: OMR adapter interface and implementation.
